# 操作工作区：持久化、输入和报告

此阶段提供离线数据层。保存任务和导入资产不会解析 DNS、连接目标或调用模型。运行启动、明确审批、模型配置存在性、权威发现存在性和报告脱敏由后续操作服务负责。

资产支持逐行文本或 UTF-8 CSV。CSV 必须包含 `target`，可含 `name`、`group`、`notes`；只有引号包裹的 notes 可跨行。导入上限 1 MiB、500 个非空数据行。预览显示默认 HTTPS、规范地址、逐行错误及重复项；重复项保留首次记录。服务必须阻止含错误的导入直接提交，让操作员明确修正或删除无效行。路径保留原样，不把不同路径误合并。

草稿必须包含名称、目标和资产。上下文、指导、排除项、GET/HEAD 工具、请求/字节/时间/并发/模型调用预算以及模型配置可选。具体字段边界和接口见 [固定接口契约](OPERATOR-DATA.md)。HTTP 资产可以保存，保存本身不授予执行权限。资产 ID 为规范目标的 SHA256 前 24 位，带 `asset_` 前缀。

草稿与运行保存在控制器专属目录的 `workspace.sqlite3`。运行冻结创建时的草稿；修改草稿不会更改已有运行。更新必须提供准确版本号，并发更新只有一个成功。草稿和运行列表返回摘要及分页，不包含完整资产/方案。运行的 campaign 路径只允许小写 UUID hex，拒绝符号链接和路径逃逸。数据层只创建父目录，campaign 初始化留给现有核心接口。

输入消息有 queued / consumed / failed 状态。相同请求编号和相同内容的重试返回原记录，不同内容冲突。记录输入、保留模型调用次数都不会自动确认模型采用了该输入。消费者名称和结果应记录实际处理结果。每个运行最多 1000 条输入；达到上限后原请求仍可重试。模型调用在请求前原子保留预算，失败或不确定也不退款，重启不会隐式重试。服务必须将未完成的调用标记 uncertain，并自行决定何时允许确认输入已被处理。

发现描述、影响、复现、修复建议及操作员补充与核心发现分开存储，保留所有叙述版本。保存叙述前服务必须检查同一运行中确实存在权威核心发现。叙述不能更改核心标题、严重性、状态、证据或独立审查结果。数据层不对核心表执行写入。

报告由服务显式组装白名单公开快照后生成，支持 HTML、Markdown、JSON。HTML 无外部资源和脚本，带 CSP，所有动态字段转义；Markdown 会转义 HTML、链接/格式和摘录中的反引号，避免代码围栏注入。报告显示停止原因、未完成覆盖、调用消耗、发现全部状态、审查、证据哈希及回执。JSON 保留公开快照；递归检测常见密钥字段只是附加检查，不能替代服务对摘录、事件、请求和结果的脱敏。覆盖观察不能证明没有漏洞，运行完成也不代表委托验收完成。

控制器根目录和数据库是受信任的本地文件。SQLite 事务提供一致性，不宣称加密或能防止具有文件写权限的人篡改；部署必须保护目录权限。状态层不执行硬状态机转换，服务必须约束审批、暂停、取消和恢复；`engagement_complete` 在当前版本始终 false。
