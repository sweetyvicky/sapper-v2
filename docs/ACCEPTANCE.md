## 交付定位

本次实现**受控 Mock 开发版**：把授权、执行预算、证据来源和风险调度落实到代码，并提供可运行命令、隔离演示和回归测试。Commander、Scout、Soldier、General、Watchdog 和原事实图均保留。当前新模式仅接受 JSON 建议，通过有界 HTTP GET/HEAD 收集观察；真实模型进程、任意 Shell 和完整自主渗透尚未接入。

演示中的独立复核是合成场景，展示证据与复核流程，不是发现真实漏洞的证明。开发和验证未接触真实目标、未扫描外部网络、未调用模型服务，不需要用户密码或 API Key。

## 已知限制与后续资源

- 新模式只支持 JSON Mock 和有界 HTTP，不能启动 Claude/Codex 等真实模型或任意工具；后续需要独立隔离适配器和专项验证。
- 默认只连接数字 IP。域名解析策略用注入结果测试，尚未启用真实域名目标支持。
- 信任主机、操作员、控制器目录及系统时钟。散列不是防恶意管理员篡改的签名；姓名也不是身份认证。比赛模式环境变量不是进程隔离。
- 字节预算只计响应体预留，排除 HTTP/TLS 线路开销；成本不是实际模型账单；风险不是自动 CVSS；覆盖键不是整台主机安全证明。
- SQLite 与文件锁依赖 Linux 本地文件系统；证据锁可能使执行串行化，数据库竞争可保守失败。当前没有状态迁移或任意改路径功能。
- 已覆盖的恢复状态不等于穷举断电与所有并发情形；不得据此声称生产级自主渗透已完成。

当前开发、测试和代码/PR 交付所需资源已满足。用户已选择现有 Linux Docker，无需新增服务器或提供密码/API Key。真实模型接入、域名及更多工具、多人操作界面、迁移和性能工作列于 [持续开发交接](DEVELOPMENT-HANDOFF.md)，后续按独立需求验收。
